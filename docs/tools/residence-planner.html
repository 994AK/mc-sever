YuHua服务器 领地规划器

在网页上画出 X/Z 范围，确认尺寸和中心点，再把命令复制到游戏里执行。这个工具不连接服务器，只帮玩家在创建前看清楚自己要圈多大。

默认限制：最多 10 个领地，单块最大 128 x 128
拖拽画一个矩形；拖动绿色中心点可移动范围；拖动四角手柄可改大小。网页坐标只用于规划，游戏里仍需要站到中心点附近执行生成的 Residence 命令。

领地参数

单位：方块

常用尺寸

范围摘要

西北角-24, -24
东南角24, 24
地面面积2,304
中心点0, 0

规范检查

游戏内命令

/res select 48 3 48
/res select vert
/res create home

进游戏后先站到中心点附近，执行选区命令，再执行 /res select vert 拉满高度；看 Residence 的边界效果满意后，再执行创建命令。

圈地规则

  • 只圈自己的建筑、机器、仓库和明确施工边。
  • 边界离建筑外 3-8 格通常足够。
  • 不要圈公共道路、公共地狱门、村庄、别人家或大片空地。
  • 超过 96x96 前先确认真的需要。
