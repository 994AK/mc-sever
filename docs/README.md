# 文档目录

文档按“什么时候用”归类，不按文件作者或临时任务归类。

| 目录 | 用途 |
| --- | --- |
| `brainstorms/` | 需求探索、玩法规则、早期范围定义 |
| `plans/` | 可执行计划、阶段拆分、验收标准 |
| `research/` | 插件选型、方案比较、外部信息整理 |
| `development/` | 开发环境、构建基线、工程约定 |
| `operations/` | 上线步骤、运行验证、冒烟测试、玩家/管理员用法 |
| `solutions/` | 复盘沉淀、长期可复用的解决方式 |
| `tools/` | 可直接打开使用的小工具 |
