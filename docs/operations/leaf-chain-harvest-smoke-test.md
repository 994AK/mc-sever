# LeafChainHarvest 冒烟测试

这份测试用于插件上线后在真实服务端确认边界。不要在服务端运行中覆盖 jar；先停服复制，再启动测试。

## 安装

1. 停服。
2. 把复制包里的 `plugins/LeafChainHarvest-0.1.0.jar` 放到服务器 `plugins/`。
3. 把复制包里的 `plugins/LeafChainHarvest/config.yml` 放到服务器 `plugins/LeafChainHarvest/config.yml`。
4. 如果要把线上旧菜单状态重置为全关，也覆盖复制包里的 `plugins/LeafChainHarvest/settings.yml`；如果要保留已经点亮的线上状态，就不要覆盖它。
5. 启动服务器，后台确认 LeafChainHarvest 正常加载。
6. 在后台执行复制包里的 `LUCKPERMS-COMMANDS.txt`。

## 管理菜单

1. 管理员进服执行 `/leafchain menu` 或 `/lch menu`。
2. 确认主菜单有 `收集`、`播种`、`耕地`、`施肥` 和农作物、木头、矿物入口。
3. 首次安装或覆盖全关 `settings.yml` 后，所有动作和材料都应显示为关闭。
4. 点亮 `收集`、`播种`、`耕地`、`施肥`，再分别进入农作物、木头、矿物页点亮本次要测试的材料。
5. 图标应在绿色允许和红色关闭之间切换；农作物页不应因甜菜、胡萝卜、马铃薯、可可豆图标报错。
6. 进入矿物页，打开 `diamond ore`，再关闭，确认状态会刷新。
7. 执行 `/leafchain reload`，菜单状态不应丢失。

## 快捷预设

1. 管理员或后台执行 `/leafchain preset farm`，全服允许农作物收集、播种、耕地、施肥和农作物材料。
2. 执行 `/leafchain preset chain`，全服允许木头和矿物材料。
3. 玩家 A 执行 `/leafchain self farm` 后，只有 A 自己启用农作物功能。
4. 玩家 B 不执行 `self` 时，即使全服已允许，也不应触发对应功能。
5. 玩家执行 `/leafchain self off` 后，自己的功能应回到关闭。
6. 管理员执行 `/leafchain preset off` 后，所有玩家都不应再触发功能。

## 农作物

1. 管理员先允许农作物功能，玩家再执行 `/leafchain self farm`。
2. 菜单里先点亮 `收集`，并点亮要测试的小麦、甘蔗、竹子、仙人掌、西瓜或南瓜。
3. 普通玩家拿到 `leafchain.crop.collect` 权限后，右键成熟小麦。
4. 小麦应正常掉落，并在原地补种为 0 龄小麦。
5. 右键未成熟小麦，应无收割动作。
6. 右键三格高甘蔗，上方甘蔗应被收集，底部甘蔗保留。
7. 右键西瓜或南瓜，应走玩家破坏路径收集。

## 播种、耕地和施肥

1. 管理员先允许农作物功能，玩家再执行 `/leafchain self farm`。
2. 菜单里先点亮 `播种`、`耕地`、`施肥`，并点亮对应作物材料。
3. 普通玩家手持小麦种子，站在多块空农田旁右键，范围内空农田上方应播种。
4. 生存模式下种子按成功播种数量消耗。
5. 普通玩家手持锄头右键草方块、泥土、砂土或土径，范围内上方为空的可耕地方块应变成耕地。
6. 普通玩家手持骨粉右键作物附近，范围内可生长作物应被施肥。
7. 生存模式下骨粉按成功施肥数量消耗。
8. 如果测试玩家没有 `leafchain.bypass-consume`，确认消耗真实发生。

## 木头和矿物

1. 管理员先允许木头/矿物材料，玩家再执行 `/leafchain self chain`。
2. 菜单里先点亮要测试的木头材料和矿物材料。
3. 普通玩家手持斧头破坏相连原木，应连锁破坏相同木头材料。
4. 相邻树叶、木板、泥土不应被连锁。
5. 蹲下破坏原木，应只破坏当前方块。
6. 普通玩家手持镐子破坏相连钻石矿，应连锁破坏相同矿物。
7. 相邻石头、深板岩、凝灰岩、地狱岩不应被连锁。
8. 在菜单里关闭 `diamond ore` 后再次测试，钻石矿不应继续连锁。

## Residence 边界

1. 创建一个测试领地，并让普通测试玩家没有 build 权限。
2. 测试玩家在该领地内尝试播种、耕地和施肥，应被跳过或提示受保护。
3. 测试玩家在该领地内尝试成熟作物右键收割，插件不应绕过自动补种权限；没有 build 权限时应跳过。
4. 测试玩家在该领地内尝试砍树、挖矿，Residence 应通过原生破坏事件阻止不允许的破坏。
5. 给测试玩家 build 权限后重试，允许位置应正常执行。

## 回滚

需要回滚时停服，删除或移走：

```text
plugins/LeafChainHarvest-0.1.0.jar
plugins/LeafChainHarvest/
```

如果只是临时禁用插件，优先把 jar 改名为 `.disabled` 后重启，保留 `settings.yml` 便于恢复。
