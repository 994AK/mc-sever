# LeafGomoku 垂直落子动画更新包

## 内容

- `plugins/LeafGomoku-0.1.0.jar`

## 本次变化

- 落子动画统一改为从目标棋盘格正上方垂直落到棋子层。
- 不再从黑白发射点抛物线飞到棋盘格。
- 方块、头颅、TNT、实体棋子都使用同一套垂直落子轨迹。
- 实体棋子保持无敌、无 AI、无重力、不可碰撞，并按固定轨迹落下。
- GUI 动画文案同步改为垂直落子/落点爆炸/实体落子。
- 保留胜利后五连消失动画。

## 部署

1. 停止服务器。
2. 把本目录里的 `plugins/LeafGomoku-0.1.0.jar` 覆盖到服务器根目录同名路径。
3. 启动服务器。

不要覆盖服务器上的 `plugins/LeafGomoku/data.db`、`rooms.yml`，这次更新不需要改数据和房间配置。

## 验证

进服开一局五子棋，点击棋盘格落子：

- 棋子应该从该格子正上方垂直落到棋盘上方一层。
- 不应该再从玩家席位或发射点抛物线飞过来。
- 实体棋子不应该能被打死，且入场轨迹应该固定。
