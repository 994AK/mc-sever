# LeafGomoku 胜利五连动画更新包

## 内容

- `plugins/LeafGomoku-0.1.0.jar`

## 作用

- 胜利后只让获胜的 5 个棋子按连线顺序消失。
- TNT/爆炸皮肤播放无伤害爆炸粒子。
- 方块/头颅皮肤播放粒子消失。
- 实体皮肤沿五连方向移动离场后自动清理。

## 部署

1. 停止服务器。
2. 把本目录里的 `plugins/LeafGomoku-0.1.0.jar` 覆盖到服务器根目录同名路径。
3. 启动服务器。

不要覆盖服务器上的 `plugins/LeafGomoku/data.db`、`rooms.yml`，这次更新不需要改数据和房间配置。

## 验证

进服开一局五子棋，让任意一方五连获胜：

- TNT 皮肤：获胜 5 个棋子逐个爆炸消失，不破坏棋盘。
- 实体皮肤：获胜 5 个实体沿连线方向离场并消失。
- 普通方块/头颅：获胜 5 个棋子逐个粒子消失。
