# CMI 简体中文语言包

把本文件夹内容复制到服务器根目录，保持目录结构覆盖即可。

包含文件：

- `plugins/CMI/config.yml`
- `plugins/CMI/Translations/Locale_CN.yml`
- `plugins/CMILib/config.yml`
- `plugins/CMILib/Translations/Locale_CN.yml`
- `plugins/CMILib/Translations/Items/items_CN.yml`

复制后建议重启服务器。仅重载可尝试：

```text
/cmil reload
/cmi reload
```

语言切换更推荐完整重启。
